# Packages

All the following packages are stored in our [GitHub monorepo](https://github.com/eslint-markdown/eslint-markdown).

## `eslint-markdown`

An ESLint plugin that provides additional Markdown rules and shared configurations. Use it alongside [`@eslint/markdown`](https://github.com/eslint/markdown#readme) to extend ESLint's Markdown support.

- [Documentation](eslint-markdown)
- [GitHub](https://github.com/eslint-markdown/eslint-markdown/tree/main/packages/eslint-markdown)
- [npm](https://npmx.dev/package/eslint-markdown)

## `eslint-lumir`

Lumir's ESLint configuration presets for JavaScript, TypeScript, React, Next.js, JSON, and Markdown. Import the configurations needed for your project from the package's subpaths.

- [Documentation](eslint-lumir)
- [GitHub](https://github.com/eslint-markdown/eslint-markdown/tree/main/packages/eslint-lumir)
- [npm](https://npmx.dev/package/eslint-lumir)

## `@eslint-markdown/parser`

A blazing fast Markdown parser for ESLint that produces an mdast syntax tree, with support for CommonMark, GFM, front matter, and math.

- [Documentation](parser)
- [GitHub](https://github.com/eslint-markdown/eslint-markdown/tree/main/packages/parser)
- [npm](https://npmx.dev/package/@eslint-markdown/parser)
